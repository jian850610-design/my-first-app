    📌 최신 수정한 내용(data.json) 전체 팀원 공유방법 (GitHub 업로드 순서)

    내 컴퓨터에서 수정한 마감일, 코멘트, 별표(★) 내용을 모든 팀원이 똑같이 보게 하려면 아래 4단계를 진행하세요.

    1 데이터 추출

    상단의 [📥 최신 데이터 내보내기] 버튼을 클릭하여 내 컴퓨터에 'data.json' 파일을 다운로드합니다.

    2 GitHub 접속 및 파일 업로드

    본인 GitHub 리포지토리(my-first-app) 메인 화면으로 이동합니다. 우측 상단 [Add file] 버튼 클릭 ➔ [Upload files]를 선택합니다.

    3 data.json 파일 끌어다 놓기

    다운로드 폴더에 있는 'data.json' 파일을 화면 중앙으로 드래그 앤 드롭(Drag & Drop) 합니다.

    4 저장 완료

    하단의 초록색 [Commit changes] 버튼을 클릭합니다. (1~2분 뒤 배포 링크로 접속하면 모든 팀원이 내가 수정한 최신 화면을 보게 됩니다!)
